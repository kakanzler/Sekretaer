# Sekretär 脅威モデル（MVP）

対象: 単一ユーザーが使うローカルのデスクトップアプリ（仕様 §3、§10、§11）。STRIDE の観点で主要な資産と信頼境界を整理する。

## 資産

| 資産 | 所在 | 機密度 |
| --- | --- | --- |
| 会議の逐語記録・ノート | SQLite（ユーザーデータ領域） | 高 |
| 録音音声（opt-in 時のみ） | データディレクトリ。会議ごとの鍵で暗号化 | 高 |
| サイドカー API token | Tauri プロセスのメモリ、サイドカーのメモリ | 高（ローカル権限の昇格につながる） |
| 同意記録 | SQLite `consent_events` | 中 |
| Claude CLI の認証情報 | CLI 自身の保存領域（アプリは扱わない） | 対象外 |

## 信頼境界

1. **WebView ⇄ Tauri Rust**: 公開する IPC は `sidecar_connection` / `sidecar_restart` / `open_privacy_settings` の 3 コマンドに限る。shell/fs プラグインは入れない。
2. **WebView ⇄ サイドカー（loopback HTTP/WS）**: 127.0.0.1 のランダムポートで bearer token を要求し、Origin を検査する。
3. **サイドカー ⇄ Claude CLI（子プロセス）**: 外部送信の境界。会議ごとに同意を得て、送信内容はプレビューで確認できる。
4. **サイドカー ⇄ OS 音声 API / モデルファイル**: 供給網の境界。

## 脅威と対策

| # | 脅威（STRIDE） | 例 | 対策 | 検証 |
| --- | --- | --- | --- | --- |
| T1 | なりすまし (S) | 同一端末の別プロセスやブラウザーのページが localhost API を叩く | ランダムポート、32 byte の token、Origin の許可リスト、JSON Content-Type の必須化 | AC-08 テスト |
| T2 | 情報漏えい (I) | ネットワーク上の他ホストからの到達 | `127.0.0.1` に限定して bind し、`0.0.0.0` を禁止 | AC-08 テスト |
| T3 | 情報漏えい (I) | token が URL、ログ、クラッシュレポートに出る | token はヘッダーまたはサブプロトコルでのみ送る。Rust とサイドカーのログではマスクする | 単体テスト（Debug 出力のマスク） |
| T4 | 権限昇格 (E) | WebView に XSS が入り任意コマンドを実行する | 厳格な CSP、remote origin の禁止、ワイルドカード capability の禁止、固定 URI 以外を開かない | `tauri.conf.json` と capability のレビュー |
| T5 | 改ざん (T) / 権限昇格 (E) | transcript 内のプロンプトインジェクションで CLI にツールを実行させる | CLI のツールを無効化し、transcript はデータとして区切って渡す。出力はスキーマで検証し、命令としては解釈しない | 偽 CLI による不正出力テスト |
| T6 | コマンドインジェクション (E) | CLI パスや引数にシェルのメタ文字を入れる | `create_subprocess_exec` と引数配列を使い、シェルを経由しない。実行ファイルは固定して解決する | コードレビュー |
| T7 | 情報漏えい (I) | 同意の範囲外に外部送信される | 外部処理 scope と要約の有効化が揃わなければジョブを作らない。同意を撤回したら待機中のジョブを取り消す | AC-01 / 同意撤回テスト |
| T8 | 否認 (R) | 同意したかどうかが後で不明になる | `consent_events` に scope、granted、ポリシー版、時刻を記録する（PII は最小化） | テスト |
| T9 | 情報漏えい (I) | 削除したはずのデータが残る | DB、音声、一時ファイル、export を削除し、WAL checkpoint を行い、失敗した範囲を報告する | AC-07 テスト |
| T10 | サービス拒否 (D) | CLI がハングする、出力が巨大になる | 120 秒のタイムアウト、stdout/stderr のサイズ上限、キャンセル時の kill | 偽 CLI テスト |
| T11 | 供給網 (T) | モデルや依存パッケージのすり替え | モデルマニフェスト（取得元、SHA-256、ライセンス）とロックファイルを使う。リリース時に記録する | `packaging/README.md`（段階 4） |

## 残余リスク・後続対応

- 同一ユーザー権限で動くマルウェアは、プロセスメモリや DB を直接読める。OS の境界を超える防御は MVP の対象外とする。
- 暗号化していない SQLite の本文は、OS のディスク暗号化に依存する。
- 自動 redaction（PII 検出）は未実装（ADR 0007）。
