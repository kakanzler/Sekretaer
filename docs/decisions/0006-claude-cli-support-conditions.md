# ADR 0006: Claude CLI の対応条件（P0）

- 状態: 仮決め
- 決定日: 2026-09-30

## 仮決め
- 要約は会議ごとに既定 OFF とする。有効化には外部処理 scope の同意を必須にし、送信内容はプレビューで確認できるようにする。
- `claude` は PATH から一度だけ解決するか、設定された絶対パスを使う。起動はシェルを経由せず引数配列で行い、`--version` で版を検出して記録する。
- CLI の認証情報はアプリで収集しない。認証が必要な場合は `cli_auth_required` を表示し、利用者が CLI 側でログインする。
- 組織の利用契約とデータ処理条件が会議テキストに適用されるかどうかは、組織管理者が確認する必要がある（§10）。確認できない環境では要約機能を無効のまま運用できる。

## 未解決
対応する CLI の最小版、出力形式フラグの互換性ポリシー、CLI 連携を禁止する組織設定の配布方法。
