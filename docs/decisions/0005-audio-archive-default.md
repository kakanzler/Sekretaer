# ADR 0005: 音声アーカイブ既定値と保持期間（P0）

- 状態: 仮決め
- 決定日: 2026-09-30

## 仮決め
- 既定は OFF。会議ごとの opt-in でのみ保存する（仕様 §10）。
- 保存する場合は、会議ごとのデータ鍵で暗号化する。鍵は OS の credential store（keyring）に置く。keyring または暗号ライブラリが使えない環境では、保存を有効化できないようにする。
- 保持期間の既定は、会議終了後 7 日とする。「即時削除」も選べるようにする。

## 未解決
保持期限が来たときの自動削除を、起動時に実行するか定期実行にするか。自動削除の通知を行うか。
