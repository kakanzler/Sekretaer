# ADR 0003: ネイティブ依存のアダプター化と縮退

- 状態: 採用
- 決定日: 2026-09-30

## 状況
faster-whisper（CTranslate2）、Silero VAD（onnxruntime/torch）、OS 音声 API（PortAudio / WASAPI loopback）は、環境によって導入できない場合や、初回にモデルの取得が必要な場合がある。仕様 §9/§12 は、要約や STT の障害があっても録音を止めないことを求める。

## 決定
- 音声取得、VAD、STT、要約のそれぞれをインターフェースの背後に置き、Python の extras（`audio`、`stt`、`vad`、`crypto`）として任意導入にする。
- 依存が無いときは、仕様付録 B のコード（`stt_model_unavailable`、`source_unavailable` など）で状態を示す。VAD はエネルギー閾値方式に縮退し、`/health` で縮退中であることを表示する。
- モデルの取得は利用者が明示的に操作したときだけ行い、事前にサイズと保存先を示す。
- テストは合成音声のソース、偽 STT、偽 CLI で行い、ネットワークにもモデルにも依存しない。

## 影響
CI やモデル未取得の環境でも全体のフローを検証できる。一方で、実音声の精度と遅延は段階 0/2 の実機評価で別途測定する必要がある（AC-10 の実機確認）。
