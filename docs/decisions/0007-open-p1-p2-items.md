# ADR 0007: P1/P2 未決事項の扱い

- 状態: 提案

| 優先度 | 事項 | 現在の実装上の扱い |
| --- | --- | --- |
| P1 | STT モデル既定 | small / int8 / CPU を暫定の既定とし、設定で変更できる。日本語精度、メモリ、p95 遅延は実機で比較する。 |
| P1 | 録音時の通知文・同意記録 | 汎用の確認チェックとポリシー版（`policyVersion`）を記録する。文面は法務レビューの後に確定する。アプリは法的同意を保証すると表示しない。 |
| P1 | 外部送信時の redaction | 送信対象のプレビューを実装済み。手動マスキングと自動 PII 検出は企業導入前に決める。 |
| P2 | 複数参加者と共有 | 対象外。単一ユーザーのローカル保存のみ。 |
| P2 | ノートスキーマ進化 | `schemaVersion` を 1.0 に固定し、`contracts/notes/note-<ver>.schema.json` を追加していく方式とする。既存の export は破壊しない。 |
